## What's fixed

- **"The server didn't start" on Windows.** On some Windows computers, Git refused Bubble AI's memory folder because the folder looked like it belonged to another user. That happens when an app ran as administrator, or when the folder is on another drive. The server then stopped with "not in a git directory". Bubble AI now trusts its own memory folders. Your Git settings aren't changed.
- **A broken memory folder.** An empty or half-made `.git` folder in memory no longer stops the server. It is repaired, and existing history is kept.
